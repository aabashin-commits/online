и контекст. Готовые выжимки лежат в `Tz/` (см. ниже).

⚠️ **Градиенты из Figma брать нельзя напрямую.** Стиль «Фоновый синий» отдаётся как
`linear-gradient(174deg, …)`, но в Figma геометрия градиента хранится относительно рамки
каждого объекта — это пересчёт под один конкретный элемент. Проверка по `1920.png`
(баннер «Приходите познакомиться», x=40 y=7570): замер (64,137,248), `135deg` даёт
(63,135,245) ✓, `174deg` — (54,110,224) ✗. В `base.css` оставлен `135deg`.

`1920.png` — ровно 1920×11415, **пиксель-в-пиксель совпадает с фреймом `1:218`**,
поэтому Y-координаты из Figma можно резать из макета напрямую, без пересчёта.

## Папка «фото тз» — единственный источник правды по дизайну

Клиент кладёт сюда макеты: цвета, шрифты, состояния, мобильные версии. **Перед вёрсткой каждого блока — просмотреть содержимое папки** (файлы добавляются по ходу проекта, названия русские).

Что уже лежит (сверяться при работе):
- `Цвета.png`, `Типографика.png` — источник для CSS-переменных в `base.css`.
- `Состояние кнопок.png`, `Эффекты.png` — ховеры/фокусы/тени для `layout.css`.
- `Форма.png`, `Форма мобайл.png` — все состояния формы для `form.css` / `form.js`.
- `360 меню.png` — мобильная шапка/бургер.
- `FAQ ответы.png` — контент аккордеона.
- `Десктоп целыый.png`, `Мобайл целый.png`, `блок 2 табы 2-5.png` — общие макеты и табы программ.
