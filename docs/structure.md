```
скул онлайн/

├── PLAN.md              — план реализации, статусы блоков, чек-лист вводных
├── 1920.png             — эталонный десктоп-макет всей страницы
├── фото тз/             — материалы от клиента (см. раздел ниже)
├── Tz/                  — выжимки из Figma и скриншоты клиента (чтобы не дёргать API повторно)
│   ├── raspisanie.md    — блок «Программы»: 3 расписания, палитра плашек, геометрия
│   ├── adaptive-1600-1200.md — замеры фреймов адаптива 1600/1200 + поп-апы формы
│   ├── mobile-360.md    — карта всех блоков мобильного фрейма 360 + расхождения
│   ├── 1921.png         — скриншот клиента: белая карточка расписания
│   └── 1922.png         — скриншот клиента: синяя карточка «пробные 2 дня»
├── index.html           — ЕДИНСТВЕННАЯ страница сайта. Городов у онлайн-школы нет,
│                          поэтому ни второго HTML, ни генератора здесь не существует
│                          (в офлайн-папке рядом лежат gelendzhik.html и build-cities.py)
├── robots.txt           — SEO: `Allow: /` + ссылка на sitemap
│                          ⚠️ TODO: домен скопирован с офлайн-сайта (agb.lancmanschool.com)
├── sitemap.xml          — SEO: 1 URL (`/`); `lastmod` обновлять при значимых правках
├── disabled-sections.html — ⚠️ НЕ подключается и НЕ заливается (в игноре sftp.json).
│                          Хранилище отключённых секций (сейчас только Тарифы;
│                          Отзывы возвращены в index.html 31.07.2026), вынесенных
│                          из index.html: HTML-комментарии видны в DOM продакшена,
│                          поэтому дремлющую разметку держим здесь, а не закомментированной
│                          в index.html. Вернуть блок — вставить <section> обратно и
│                          раскомментировать ссылки меню. См. раздел «Деплой».
├── favicon.ico  favicon.svg  favicon-96x96.png  apple-touch-icon.png
│                        — ⚠️ это **дубли** корня, а не основной набор. Канонический
│                          комплект лежит в `assets/favicon/` — именно на него ссылается
│                          `<head>`. Корневые копии нужны для случая, когда браузер или
│                          робот запрашивает `/favicon.ico` сам, не читая разметку
│                          (так делает часть поисковиков). `site.webmanifest` и
│                          `web-app-manifest-*.png` в корне **отсутствуют** и не нужны:
│                          на них никто не ссылается (в корне отдают 404 — это норма)
├── assets/
│   ├── favicon/         — **канонический набор фавиконок** (realfavicongenerator, 21.07.2026):
│   │                      `favicon.ico` (3 кадра 48/32/16), `favicon.svg`, `favicon-96x96.png`,
│   │                      `apple-touch-icon.png`, `site.webmanifest`,
│   │                      `web-app-manifest-192x192.png`, `web-app-manifest-512x512.png`.
│   │                      В `<head>` пути **без ведущего слэша** (`assets/favicon/…`) —
│   │                      чтобы работали и в подпапке домена. В манифесте пути к иконкам
│   │                      относительные, поэтому резолвятся в ту же папку;
│   │                      `theme_color` приведён к фирменному #366EDF (в исходнике был белый)
│   ├── fonts/           — Onest variable (woff2, сабсеты cyrillic/latin/latin-ext, OFL.txt)
│   ├── img/             — по подпапкам блоков: hero/, attestat/, about/, pricing/, programs/, ...
│   │   ├── staff/           — фото педагогов блока 12: главное круглое `<slug>.webp`
│   │   │                       (кроп «голова+плечи» из презентации) + вырезка без фона
│   │   │                       `<slug>-thumb.webp` (rembg/u2net) для миниатюры
│   │   ├── reviews/         — постеры 15 видео-отзывов, `<slug>.webp` 850×600
│   │   │                       (= плитка 425×300 при DPR 2; кадр 16:9 обрезан по бокам)
│   │   ├── school/          — постеры 3 обзорных роликов, `<slug>.webp` 1740×978 (16:9)
│   │   ├── logo.svg         — цветное лого (шапка, мобильное меню)
│   │   ├── logo_footer.svg  — белое лого (футер)
│   │   └── og-cover.jpg     — SEO-превью 1200×630 (og:image/twitter). Сгенерировано нами
│   │                          из hero; заменить, если клиент пришлёт свой баннер
│   └── video/           — ролики (31.07.2026), 180 МБ. Заливаются на прод как обычные файлы
│       ├── reviews/         — 15 видео-отзывов `<slug>.mp4`
│       └── school/          — 3 обзорных ролика `<slug>.mp4`
├── css/
│   ├── base.css         — reset, CSS-переменные (цвета/шрифты/радиусы/тени), типографика
│   ├── layout.css       — контейнер, общие компоненты: кнопки, пиллы, бейджи, заголовки секций
│   ├── header.css   hero.css   info-cards.css   attestat.css
│   ├── onschool.css   who-fits.css   school-day.css   programs.css
│   ├── classes.css   about.css
│   ├── formats.css   pricing.css   additional.css   reviews.css
│   ├── trial.css   faq.css   footer.css
│   ├── form.css   mobile-cta.css
│   ├── ege-banner.css   universities.css   consultation.css   — ⚠️ НЕ подключены: секции лежат в disabled-sections.html
└── js/
    ├── main.js          — инициализация, общие хелперы (smooth scroll, каркас лайтбокса, открытие модалки формы, `createScroller()` — горизонтальные ленты со стрелками, `createPager()` — листание страницами (отзывы, обзорные ролики), `lockScroll()`/`unlockScroll()` — блокировка страницы под модалками, `applyLazySrc()` — ленивая загрузка картинок, которые создаёт JS (см. раздел «Изображения»)); здесь же слой состояния `window.schoolChoice` + сеттеры `setSchoolStage` / `setEducationFormat` / `setPrice`, рассылающие событие `school-choice`
    ├── analytics.js     — цели Яндекс.Метрики (§22 ТЗ): десять событий одним делегированным слушателем, блоки о нём не знают. Цель заявки — только по событию Битрикса, не по клику. ⚠️ ID счётчика в файле — счётчик ОФЛАЙН-школы
    ├── header.js        — только бургер-меню (липкость шапки — CSS). Выпадающие списки удалены 07.09.2026 по §4 ТЗ
    ├── mobile-cta.js    — липкая плашка CTA на телефоне: появляется после ухода CTA первого экрана, прячется на #pricing и #trial (#consultation убран 10.09.2026, скрипт переживает это сам)
    ├── attestat.js      — лайтбокс документа секции «Аттестат»
    ├── programs.js      — «Образовательные программы» внутри секции учебного дня: данные 3 ступеней + рендер сетки расписания, выравнивание высоты карточки по самой высокой программе. Заменил `school-day.js` 10.09.2026 (перенос блока со старого сайта)
    ├── classes.js       — ступени-аккордеоны, выбранная ступень пишется в состояние
    ├── about.js         — команда школы: данные сотрудников, шесть профилей + показать всех
    ├── formats.js       — сравнение двух форматов, выбор пишется в состояние и активирует формат в стоимости
    ├── pricing.js       — тарифы: переключатель ступеней, состав тарифа (на телефоне сворачивается)
    ├── additional.js    — дополнительные направления, полный список по кнопке
    ├── reviews.js       — видео-отзывы: данные 15 роликов, рендер плиток, открытие в лайтбоксе
    ├── faq.js           — аккордеон, 11 вопросов из §17 ТЗ
    ├── consultation.js  — ⚠️ НЕ подключён: финальная форма §18 (валидация, скрытые поля, экран успеха по событию Битрикса). Секция «Поможем выбрать класс и формат обучения» убрана 10.09.2026, разметка в disabled-sections.html
    ├── form.js          — маска +7, валидация, отправка, состояния, модалка успеха (кастомная форма ОТКЛЮЧЕНА, см. bitrix.js)
    └── bitrix.js        — переопределяет window.openForm ПОСЛЕ form.js: все CTA открывают CRM-форму Битрикс24 через клик по скрытому .b24-trigger; кастомная модалка больше не всплывает. Номера формы файл не знает — он в разметке (⚠️ сейчас там click/225 — форма ОФЛАЙН-школы, см. «Онлайн-версия»)
```
