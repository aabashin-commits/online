# Лендинг онлайн-школы «Моя школа LS»

Одностраничный лендинг: чистые HTML + CSS + vanilla JS, без сборщиков, npm
и фреймворков. Открывается прямо в браузере — точка входа `index.html`.

Сделан 12.08.2026 копией офлайн-лендинга той же школы: структура блоков, сетка
и адаптив общие, переписаны тексты и убрано всё городское (переключатель
Москва/Геленджик, карта филиалов, адреса в футере).

## Как запустить локально

MCP-браузеры и часть проверок не работают по `file://`, поэтому поднимаем сервер:

```sh
python3 -m http.server 8765
# http://localhost:8765/index.html
```
